# PRMAX — лендинг (сайт + реклама Google)

Одностраничный сайт PRMAX: сайт $300 + реклама Google $100, бонус Google до 10 000 ₴, украинский язык, вся Украина и Европа.

- `index.html` — текущая версия (v4, 23.10.2026): телефон в приоритете, бургер-меню, карусели, конструктор рекламы.
- `index-v3-23.10.html` — предыдущая версия v3 (компьютерная, с длинными текстами).
- `img/`, `video/` — фото (Unsplash), логотип, работы и отзывы из проекта PR MAX на Тильде.
- Контакты — блок `CONTACTS` в конце `index.html` (сейчас заглушки).

Локальный запуск: `python3 -m http.server 8787` в этой папке → http://127.0.0.1:8787/
